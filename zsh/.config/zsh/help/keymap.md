# zsh keymap 速查

## 模式

- `bindkey -v` - 启用 vi 模式
- `bindkey -e` - 启用 emacs 模式

## 当前配置（本机）

- `Ctrl+X Ctrl+E` - 打开编辑器编辑当前命令
- `Alt+V` - 打开编辑器编辑当前命令
- `Ctrl+\` - 接受 autosuggest
- `Ctrl+N` - 接受 autosuggest

## 常用内置快捷键

- `Ctrl+A` - 行首
- `Ctrl+E` - 行尾
- `Ctrl+U` - 清除光标前内容
- `Ctrl+K` - 清除光标后内容
- `Ctrl+W` - 删除前一个单词
- `Ctrl+R` - 反向搜索历史
- `Alt+.` - 插入上条命令的最后一个参数

## vi 模式常用

- `Esc` - 进入命令模式
- `i` - 进入插入模式
- `dd` - 删除当前行
- `dw` - 删除一个单词
- `0` - 行首
- `$` - 行尾
- `p` - 粘贴
