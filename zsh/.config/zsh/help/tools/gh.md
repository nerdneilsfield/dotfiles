# gh (GitHub CLI)

GitHub 命令行。

## 常用命令
- `gh auth login`
- `gh repo clone owner/repo`
- `gh repo view`
- `gh pr create`
- `gh pr list`
- `gh issue list`

## 常用参数
- `--web` 在浏览器打开
- `--json` 输出 JSON

## 使用案例
- `gh auth login`
- `gh repo clone owner/repo`
- `gh pr create`
- `gh pr list`
- `gh issue list`

## 配合使用
- `gh repo list --limit 200 | fzf` 选择仓库
