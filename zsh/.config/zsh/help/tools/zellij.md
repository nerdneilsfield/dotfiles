# zellij

终端复用器。

## 常用命令
- `zellij`
- `zellij ls`
- `zellij attach name`
- `zellij delete-session name`
- `zellij --layout layout.kdl`

## 说明
- 默认前缀键 `Ctrl + g`

## 使用案例
- `zellij`
- `zellij ls`
- `zellij attach name`
- `zellij delete-session name`

## 配合使用
- `zellij --layout layout.kdl`
