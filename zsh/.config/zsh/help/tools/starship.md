# starship

跨 shell 的 prompt。

## 常用命令
- `starship init zsh` (写入 rc)
- `starship preset plain-text -o ~/.config/starship.toml`
- `starship --help`

## 配置
- `~/.config/starship.toml`

## 使用案例
- `starship init zsh`
- `starship preset plain-text -o ~/.config/starship.toml`
- `starship --help`

## 配合使用
- `rg "^\[" ~/.config/starship.toml` 查配置段
