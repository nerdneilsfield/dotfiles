# Mole (mo)

Mac 清理与优化工具。

## 常用命令
- `mo` 交互菜单
- `mo clean` 深度清理
- `mo uninstall` 彻底卸载应用
- `mo optimize` 优化系统
- `mo analyze` 磁盘分析
- `mo status` 系统监控
- `mo update` 更新
- `mo remove` 卸载

## 常用参数
- `--dry-run` 预览
- `--whitelist` 白名单
- `--debug` 调试日志

## 使用案例
- `mo` 交互菜单
- `mo clean`
- `mo uninstall`
- `mo optimize`
- `mo analyze`
- `mo status`

## 配合使用
- `mo clean --dry-run` 先预览再执行
