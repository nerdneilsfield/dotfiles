### template<typename ActionT>
class rclcpp\_action::Server< ActionT >

Action [Server](https://docs.ros2.org/latest/api/rclcpp_action/classrclcpp__action_1_1Server.html "Action Server.")
.

This class creates an action server.

Create an instance of this server using `[rclcpp_action::create_server()](https://docs.ros2.org/latest/api/rclcpp_action/namespacerclcpp__action.html#aac27305f020b4586d4ae781024ac80e4 "Create an action server.") `.

Internally, this class is responsible for:

*   coverting between the C++ action type and generic types for `[rclcpp_action::ServerBase](https://docs.ros2.org/latest/api/rclcpp_action/classrclcpp__action_1_1ServerBase.html) `, and
*   calling user callbacks.

Construct an action server.

This constructs an action server, but it will not work until it has been added to a node. Use `[rclcpp_action::create_server()](https://docs.ros2.org/latest/api/rclcpp_action/namespacerclcpp__action.html#aac27305f020b4586d4ae781024ac80e4 "Create an action server.") ` to both construct and add to a node.

Three callbacks must be provided:

*   one to accept or reject goals sent to the server,
*   one to accept or reject requests to cancel a goal,
*   one to receive a goal handle after a goal has been accepted. All callbacks must be non-blocking. The result of a goal should be set using methods on `[rclcpp_action::ServerGoalHandle](https://docs.ros2.org/latest/api/rclcpp_action/classrclcpp__action_1_1ServerGoalHandle.html "Class to interact with goals on a server.") `.
