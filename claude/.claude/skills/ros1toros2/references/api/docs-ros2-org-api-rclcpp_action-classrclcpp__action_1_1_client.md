Detailed Description
--------------------

### template<typename ActionT>
class rclcpp\_action::Client< ActionT >

Action [Client](https://docs.ros2.org/latest/api/rclcpp_action/classrclcpp__action_1_1Client.html "Action Client.")
.

This class creates an action client.

To create an instance of an action client use `[rclcpp_action::create_client()](https://docs.ros2.org/latest/api/rclcpp_action/namespacerclcpp__action.html#aebd56d58afc9b7c0c5b3e58cb1613ebd "Create an action client.") `.

Internally, this class is responsible for:

*   coverting between the C++ action type and generic types for `[rclcpp_action::ClientBase](https://docs.ros2.org/latest/api/rclcpp_action/classrclcpp__action_1_1ClientBase.html) `, and
*   calling user callbacks.

Send an action goal and asynchronously get the result.

If the goal is accepted by an action server, the returned future is set to a `[ClientGoalHandle](https://docs.ros2.org/latest/api/rclcpp_action/classrclcpp__action_1_1ClientGoalHandle.html "Class for interacting with goals sent from action clients.") `. If the goal is rejected by an action server, then the future is set to a `nullptr`.

The returned goal handle is used to monitor the status of the goal and get the final result. It is valid as long as you hold a reference to the shared pointer or until the [rclcpp\_action::Client](https://docs.ros2.org/latest/api/rclcpp_action/classrclcpp__action_1_1Client.html "Action Client.")
 is destroyed at which point the goal status will become UNKNOWN.
